# FLN Rating

Статистика CS2 от **Fuluny Corporation**. MVP v0.1: живые матчи, рейтинг VRS и профиль игрока.

## Что уже работает
- 🎮 **Live-матчи**: счёт и статус текущих игр (с кешированием, чтобы не тратить лимиты API).
- 🏆 **Рейтинг VRS**: топ-20 команд по официальному рейтингу Valve с динамикой позиций.
- 👤 **Мой профиль**: запоминает твой Steam ID и даёт быстрый переход к детальной статистике на Leetify.

## Дизайн
- Тёмная тема в стиле CS2.
- Минимализм: только самое важное, без лишнего шума.
- Фирменные акценты Fuluny.

## Стек
- HTML5 / CSS3 / Vanilla JS
- GitHub Pages (хостинг)
- API: citoapi.com (CS2 данные)
